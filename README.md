## 📸 Key Highlights & Features

- 🏎️ **Creator 4-Hour Shoot Passes:** Specifically tailored for reels, YouTube shorts, and commercial shoots without paying for full 24-48 hours.
- 📱 **"Shot on IGNITE" Viral Reels Gallery:** Proof-of-virality cards showcasing view metrics (4.2M views, 2.8M views) and creator handles.
- 🏷️ **"Tag & Save" 15% Creator Subsidy:** Dynamic algorithm offering 15% instant discount to creators who tag `@ignite.wheels` in their content.
- ⚡ **Dynamic Fleet Catalog & Real-Time Search:** Real-time filter pills (Supercars, Track, Muscle, Spyders, SUVs) and search box powered by native ES6 `Array.filter()`.
- 🧮 **Interactive Production Estimator (Modal):** Instant price calculations including optional creator add-ons (GoPro rig, Precision Stunt Driver, Studio RGB lights).
- 💬 **One-Click WhatsApp Deep Linking:** Auto-generates pre-formatted shoot inquiry messages with sanitized URL encoding (`encodeURIComponent`).
- 🎨 **Cyber Cyan Visual Identity:** Futuristic dark obsidian theme (`#07090E`) with high-voltage Cyber Cyan (`#00F0FF`) glows and glassmorphism.

## 🛠️ Built With

- **Structure:** Semantic HTML5 (`header`, `nav`, `section`, `article`, `details`)
- **Styling:** Tailwind CSS (via CDN) + Custom Cyber Cyan CSS variables (`style.css`)
- **Logic & DOM:** Vanilla JavaScript (ES6+) — Zero external runtime dependencies
- **Deployment:** Vercel / GitHub Pages

## 🚀 Local Setup

Because this project is built with zero build tools or complex dependencies:

1. Clone this repository:
   ```bash
   git clone https://github.com/<your-username>/ignite-studio-wheels.git
   ```
2. Open `index.html` directly in your browser, or run a live server:
   ```powershell
   python -m http.server 3000
   ```
3. Visit `http://localhost:3000`.
